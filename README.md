## 📖 О проекте

**CleanTrace** — это инструмент, который помогает обычному пользователю узнать, какие его данные уже гуляют по рукам. Бот проверяет email и пароли на наличие в публичных базах утечек и выдаёт понятный отчёт.

Проект создан как **защитный инструмент**, а не как «пробив». Бот не собирает, не хранит и не передаёт данные пользователей третьим лицам.

> ⚠️ **Дисклеймер:** данные об утечках получены из публичных источников и не верифицируются. Наличие или отсутствие информации не подтверждает и не опровергает факт утечки.

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📧 **Проверка email** | Поиск в публичных базах утечек через XposedOrNot API |
| 🔑 **Проверка паролей** | Через Pwned Passwords API (k-anonymity, SHA-1) |
| 🌟 **Обратная связь** | Сбор оценок и комментариев от пользователей |
| 💛 **Донаты** | Приём поддержки через CloudTips (Т-Банк) |
| ℹ️ **Команды** | `/start`, `/help`, `/about`, `/password`, `/donate`, `/feedback` |

## 🔒 Безопасность

| Что делаем | Как |
|-----------|-----|
| **Email** | Отправляется в публичный API XposedOrNot. Не сохраняется на сервере. |
| **Пароли** | Хешируются (SHA-1). Передаётся только первые 5 символов хеша (k-anonymity). Сам пароль никуда не уходит. |
| **Логи** | Бот не ведёт логи пользователей и не хранит историю запросов. |

**Проверка пароля по k-anonymity:**
1. Пароль → SHA-1 хеш
2. Первые 5 символов хеша отправляются в API
3. API возвращает список хвостов
4. Локально проверяем, есть ли наш хвост
5. Сам пароль и полный хеш остаются только на сервере
